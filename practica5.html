Practica 5: Aplicacion de estilos con CSS

Explicacion

En esta practica se introduce el uso de hojas de estilo en cascada mediante el archivo practica5.css. CSS permite separar el contenido HTML del disenio visual de la pagina, facilitando su mantenimiento y personalizacion. Se utilizan diferentes selectores para aplicar estilos a los elementos HTML y modificar propiedades como color para cambiar el color del texto, background-color para establecer colores de fondo, font-size para ajustar el tamanio de la letra y font-family para cambiar el tipo de fuente. Tambien se emplean propiedades como margin y padding para controlar los espacios entre elementos. La pagina incluye un menu de navegacion construido mediante las etiquetas ul, li y a, permitiendo acceder a diferentes secciones del sitio. El objetivo de esta practica es aprender a mejorar la apariencia y organizacion visual de una pagina web mediante el uso de CSS.
