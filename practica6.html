Práctica 6: Integración de HTML y CSS

Explicación

En esta práctica se integran los conocimientos adquiridos de HTML y CSS para construir una página web más completa y organizada. Se utilizan encabezados para mostrar títulos y secciones importantes, enlaces mediante la etiqueta a para facilitar la navegación y la etiqueta img para incorporar imágenes dentro del contenido. La estructura general de la página se divide en diferentes áreas como encabezado, menú de navegación, contenido principal, sección lateral y pie de página. El diseño visual es controlado mediante el archivo practica6.css, donde se definen colores, tamaños, márgenes, posiciones y distribución de los elementos. Esta práctica permite comprender cómo HTML proporciona la estructura del sitio mientras que CSS se encarga de su apariencia visual. El objetivo es desarrollar una página web funcional y organizada que simule la estructura de un sitio web profesional.
